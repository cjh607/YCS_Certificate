# 📚 자격증 통합정보 플랫폼

> 여러 기관에 흩어져 있는 자격증 정보를 수집·정규화하여 한눈에 제공하고,
> CBT 모의시험 기능까지 지원하는 통합 플랫폼
------------------------------------------------------------------------

## 🔎 Overview

국내 자격증은 기관별 사이트에 분산되어 있어 사용자가 각각의 사이트를
방문해야 정보를 확인하고 시험을 신청해야 하는 불편함이 존재합니다.

본 프로젝트는 이러한 문제를 해결하기 위해 다양한 자격증 정보를 자동
수집하고 통합하여 제공하는 플랫폼을 목표로 개발되었습니다.

-   Python 기반 크롤링 엔진으로 최신 자격증 정보 수집
-   데이터 정규화 후 DB 저장
-   사용자 맞춤형 자격증 관리 기능 제공
-   CBT 모의시험 시스템 구현
