# 📚 자격증 통합정보 플랫폼

> 여러 기관에 흩어져 있는 자격증 정보를 수집·정규화하여 한눈에 제공하고,
> CBT 모의시험 기능까지 지원하는 통합 플랫폼
------------------------------------------------------------------------

## 🔎 Overview

국내 자격증은 기관별 사이트에 분산되어 있어 사용자가 각각의 사이트를
방문해야 정보를 확인하고 시험을 신청해야 하는 불편함이 존재합니다.

본 프로젝트는 이러한 문제를 해결하기 위해 다양한 자격증 정보를 자동
수집하고 통합하여 제공하는 플랫폼을 목표로 개발되었습니다.

-   Python 기반 크롤링 엔진으로 최신 자격증 정보 수집
-   데이터 정규화 후 DB 저장
-   사용자 맞춤형 자격증 관리 기능 제공
-   CBT 모의시험 시스템 구현

------------------------------------------------------------------------

## 🚀 Key Features

### 1️⃣ 자격증 정보 통합 수집 시스템

-   Python 기반 크롤링 엔진 개발
-   각 기관 사이트의 자격증 정보 수집
-   수집 데이터 정규화 후 DB 저장
-   "자격증 정보 불러오기" 버튼 클릭 시 최신 데이터 갱신

### 2️⃣ 자격증 탐색 기능

-   초성 검색 지원
-   자격증 목록 및 상세 정보 조회
-   학과 기반 연관 자격증 추천
-   자격증 즐겨찾기 기능
-   관심 자격증 시험 일정 한눈에 확인

### 3️⃣ 자체 개발 캘린더 시스템

-   자격증 시험 일정 시각화
-   즐겨찾기 기반 개인 맞춤 일정 확인

### 4️⃣ CBT 모의시험 시스템

-   실제 CBT 방식과 동일한 랜덤 문제 출제 로직 구현
-   시험 종료 후 자동 채점
-   오답노트 제공
-   시험 기록 저장
-   사용자별 응시 이력 관리

### 5️⃣ 인증 및 보안

-   JWT 기반 인증 시스템
-   OAuth 소셜 로그인 (Google, Kakao)
-   Redis 기반 토큰 관리
